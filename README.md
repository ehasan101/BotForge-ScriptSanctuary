## Get Started
### 1. **Clone the Sanctuary**: <br>

   
**::: For Python Playwright :::** <br>
   

   
Before running the script, you need to have the following installed on your system:
- Python 3.7+
- pip (Python package installer)
      
**Installation** <br>
Clone the repository (or download the script):
```bash
git clone https://github.com/ehasan101/BotForge-ScriptSanctuary.git
```
```bash
cd BotForge-ScriptSanctuary 
```
      
- **Install Playwright:** <br>
Open terminal or command prompt and run the following command to install the Playwright library for Python:
`pip install playwright`

- **Install browser binaries:** <br>
Playwright requires browser binaries to automate browsers. Install them with this command:
`playwright install`

      
**How to Run the Scripts!** <br>
      Once the installation is complete, you can run the Python script from your terminal:
      
```Bash
python fileName.py
```
_All scripts are configured to run with **headless=False** so it will open a visible Chromium browser window to show the automation steps in real-time._
